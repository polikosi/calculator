# Калькулятор завантаження палет і фури

Веб-калькулятор для менеджерів і логістів: рахує коробки на палетах, вагу палет і загальну вагу продукту у фурі, перевіряє ліміти і показує схему причепа збоку.

**Відкрити:** https://polikosi.github.io/kalkulator/

## Можливості
- Довідник товарів: вага коробки, макс. вага палети, макс. коробок на палеті.
- Позиції завантаження з клієнтами; кількість у кг, коробках, палетах або «Заповнити фуру».
- Підсумки, вільний залишок, підсумок по клієнтах.
- Перевірки лімітів палети, ваги фури (19 880 кг) і місць (33).
- Схема причепа: колір за клієнтом, неповні палети — пунктирна рамка на ближньому боці.
- Експорт у PDF.

## Як це працює
Один файл `index.html` (HTML + CSS + JavaScript), без сервера. Дані кожного користувача зберігаються в його браузері (localStorage). Для PDF потрібен інтернет — бібліотека pdfmake підвантажується з CDN.
